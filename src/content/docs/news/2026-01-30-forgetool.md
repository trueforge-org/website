Trueforge has released Forgetool, an updated cluster tool to help bootstrap and maintain Kubernetes clusters running on Talos Linux.

Forgetool is the continuation of the original Clustertool, with updated internals and workflows. It is now part of most of Trueforge’s CI pipelines, meaning it is tested in the same way it’s used internally.

## Changes in This Release

- Support for Talos Linux 1.12
- Updated and adjusted commands
- Ongoing cleanup and restructuring of the tool

More changes and features are planned for future releases.

## Additional TrueCharts Update

Alongside Forgetool, Trueforge has released a new chart for TrueCharts:

Hytale Server Helm Chart, enabling deployment of Hytale servers on Kubernetes

## Whats to come?

We are hard at work on expanding containerforge library of image to be used for both our helm-charts as well as for Docker.
