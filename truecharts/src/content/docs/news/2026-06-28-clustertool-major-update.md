## Clustertool Is Back

Clustertool 4.0.0 is here. This release brings Clustertool back in full force,
with a cleaner experience and the same practical workflow many of you already know and rely on.

See all release artifacts here: [Clustertool releases](https://github.com/trueforge-org/clustertool/releases).

## License Update: Now AGPL

Starting with this release, Clustertool is licensed under AGPL.
This keeps the project open and collaborative while making sure improvements remain available to the wider community.

## Platform Support

Clustertool 4.0.0 includes support for Talos 1.13.x and Kubernetes 1.36.x, so you can move forward on modern cluster stacks with confidence.

## Simpler Commands, Better Structure

We simplified the command structure to make common tasks easier to discover and run.
We also updated the layout and chart setup, including removing and rearranging multiple folders for a more maintainable project structure.

For the full command reference, please check the [maintenance guide](../guides/clustertool/maintenance.md).

## New Maintenance and Cleanup Tasks

This version adds:

- Longhorn cleanup tasks
- Image garbage collection
- And many many chart updates

These additions help reduce manual cleanup work and keep clusters healthier over time.

## Stronger Release Quality

We expanded automated testing for Clustertool releases to improve reliability and catch issues earlier in the release process.

## Thank You

Thank you to everyone who tested, reported issues, and shared feedback while we worked on this major refresh.
Clustertool 4.0.0 is an important step forward, and we are excited to keep building with the community.
